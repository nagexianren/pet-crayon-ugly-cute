# 品种特征库

按品种查招牌特征与毛发画法，填入提示词的【招牌特征】段。

## 通用判断法

**招牌特征＝原照里那块和同品种其他个体不一样的地方。** 不一定在耳朵上，面部斑纹、额头纹路同样有效。

拆成「1 个招牌 ＋ 3 个辅助」，每条后接互斥否定。

## 常见品种

| 品种 | 招牌特征 | 耳朵写法 | 毛发画法 | 毛色要点 |
|---|---|---|---|---|
| 柯基 | 额头白色竖中线从上到鼻梁 | `POINTED TRIANGLE UP 大三角立耳`，耳内肉粉三角 | `SHORT DENSE FUR 短密`，小笔触均匀铺 | 橘棕 #D08A4A 为主，奶白 #F5EFE2 在额线鼻周下巴；深橘棕 #B26B33 标示层次 |
| 约克夏 | 尖三角立耳 ＋ 三色 | `POINTED TRIANGLE UP 尖三角立耳！… 绝对不要画成垂耳，不要圆耳朵` | `LONG STRAIGHT SHAGGY 长直乱毛`，尖细笔画向下散 | 三色按部位：头顶及脸颊外侧 #3B3A38、嘴周及下巴 #C9A882、眼周 #D8C0A0 |
| 贵宾 | 眼周灰褐色斑纹 ＋ 圆卷耳 | `ROUND CURLY 圆卷耳`，两团大卷毛紧贴脸侧 | `CURLY FLUFFY 卷毛`，多个小圆叠蓬松感 | 奶油杏 #E8CBA0，高光 #F5E3C4；或纯白用三层明度 |
| 泰迪／卷毛比熊 | 圆头 ＋ 卷毛炸开 | `SMALL CURLY 小卷耳`（泰迪）／`BIG DROOPY 大垂耳`（比熊） | `CURLY FLUFFY`，多个小圆叠蓬松感 | 白犬用三层明度；垂耳外侧用浅灰 #DCD6CC 分层 |
| 比熊 | 圆头 ＋ 顺毛平涂 | `BIG DROOPY 大垂耳` 垂到脸颊下缘 | `SMOOTH FLAT 顺毛`，大块平涂边缘干净 | 白犬三层明度 |
| 柴犬 | 立耳 ＋ 脸上白吻部 | `POINTED TRIANGLE UP 尖三角立耳` | `SHORT DENSE FUR 短密` | 赤褐 #C0703C 为主，奶白在口鼻、下巴、脸颊内侧、眉间 |
| 博美 | 立耳 ＋ 极蓬松围脖 | `SMALL POINTED UP 小立耳` | `FLUFFY 蓬松`，大量小圆叠出爆发感 | 全身单一色即可，靠体型蓬松度取胜 |
| 法斗 | 大立耳 ＋ 扁脸黑鼻 | `BIG BAT EAR 大蝙蝠耳`，耳圆而大 | `SHORT DENSE FUR 短密` | 脸部**必须大面积奶白**；身体可有花斑但脸保持干净 |
| 哈士奇／边牧 | 面部白色 blaze 分区 | 视个体（立耳或半垂） | `LONG STRAIGHT SHAGGY` 或 `FLUFFY` | **脸部按区域分色**：鼻梁白条、脸颊色块、眼周围色，用色块拼而非渐变 |
| 猫（折耳／立耳） | 头型 ＋ 耳型 | `FOLDED DOWN 前折耳`／`POINTED UP 直立三角耳` | `SHORT SOFT FUR 短软毛`，大面积平涂 | 纯色或虎斑色块；虎斑用深色细条纹写在下巴和脸颊内侧 |
| 兔子 | 长垂耳 ＋ 大眼睛 | `LONG DROOPY 长垂耳`，垂到脸两侧 | `FLUFFY 蓬松` | 纯白用三层明度，耳朵内侧淡粉 |

## 白色宠物三层明度（必用）

```
主体色 #F2EDE0 暖奶白 —— 铺底
高光色 #FFFFFF 纯白 —— 额头、脸颊
结构色 #DCD6CC 浅灰 —— 耳尖、头顶、下巴
```

不写这三层，白毛会糊成一片死白。

## 猫与狗的差异

| 项 | 狗 | 猫 |
|---|---|---|
| 脸型 | 圆或长椭圆，吻部可简化省略 | 更尖更短，保留倒三角颊 |
| 鼻 | 圆黑或倒三角 | 小三角，偏小 |
| 耳 | 品种差异极大 | 主要是折耳／立耳／圆耳三种 |
| 胡须 | 可加三根 | 通常省略或加两根 |
| 眼占比 | 40%~47% | 略降到 38%~42%（猫本身眼睛就大，再大显突兀） |

## 提示词参数建议

| 场景 | input_fidelity |
|---|---|
| 单宠，特征明显 | `medium` |
| 双宠，必须区分 | `high` |
| 品种特征极强（柯基额线、贵宾眼斑） | `high` |
