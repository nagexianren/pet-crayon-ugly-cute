# 提示词模板

每次生成时读取本文件，按宠物照片的实际特征填入方括号内容。

## 单次出图规则（硬性）

每次用户请求“生成”只运行一次图像生成任务，并返回一张图。双宠图的两只宠物画在同一张画布中，不拆成单宠，不制作备选图。严格遵循用户已确认的本技能要求和对应模板；除非用户明确要求，否则不更改构图、帽子、眼睛、无嘴规则、宠物特征或背景选择标准。工具处理中时等待同一任务；图片未显示时检查已有调用结果，不要再发起一次生成。仅在确认任务失败且没有任何成图，或用户明确要求重做时，才再次提交，且仍只生成一张。
## 模板结构（单宠）

```
把照片里这只[宠物称呼]，改画成儿童蜡笔画（crayon / oil pastel）风格的手绘插画。生成时附上用户宠物照片、通用风格参考、眼睛样板 `references/眼睛参考-用户认可双宠.png`；生成单只狗时额外附上 `references/单犬参考-用户认可帽子头像.png`。眼睛样板只约束眼睛；单犬样板只提供头像构图和画法，不复制样板宠物的品种、毛色或帽子颜色。

【最高原则：严格复刻参考画风】
画面里 ONLY 有：[圆形头部]、[两只耳朵]、[一对巨大眼球]、[一个鼻子]、[一小截脖子]、[一顶必须出现的毛线帽]。
除毛线帽外不出现任何道具；不要身体、不要爪子、不要腿、不要尾巴、[原照背景杂物清单]。大面积留白，脸部不要堆砌细节。干净感来自"少"。

【构图 — 严格照搬参考图】
1. 一个正圆形的头，居中，占画面约六成，[下巴略方／脸颊鼓出等头型描述]。
2. 头下方只接一小截细窄的脖子，[脖子毛色描述]。
3. 毛线帽必须出现；只保留毛线帽，不出现其他道具，且不得遮住双耳和招牌花纹。

【招牌特征 — 必须抓住】
4. [招牌特征 1，按部位写死，带英文大写关键词]
5. [招牌特征 2]
6. [招牌特征 3]
7. [招牌特征 4]
每条特征后接互斥否定：「绝对不要画成[错误形态]」。

【眼睛 — 画面主角，最后画】
8. 眼睛严格参考 `references/眼睛参考-用户认可双宠.png`：两只巨大白色正圆眼，间距很窄，粗黑略不规则描边，视觉大小比例与样板一致，不要额外放大。
9. 眼白是 HUGE 的纯白色 #FFFFFF，几乎占满整个眼球。
10. 瞳孔是 EXTREMELY SMALL 的小黑点，位于眼球正中，约占眼白直径 15%~20%。
11. 眼睛的粗黑描边比脸部其他线条都粗，形成强烈黑框感。
12. 眼神呆滞、空洞、发愣。眼睛样板只参考眼部，不复制其中的宠物、帽子、构图、颜色或背景。若眼睛样板未传入，使用占脸宽各约四成的通用比例。
【毛发】
13. [毛发画法：多个小圆叠蓬松感／尖细笔画向下散／大块平涂边缘干净]
14. [毛色分层，按部位写清哪个部位用哪个色码]

【鼻子与嘴】
15. 鼻子是一个[倒三角／圆形][黑色／粉色]鼻子 #______，位于两眼正下方中央。
16. ABSOLUTELY NO MOUTH，绝对不要画嘴巴，不要嘴缝，不要微笑线，不要嘴唇，不要吐舌头。只在鼻子正下方画一根短短的黑色竖线到下巴。其余全部留白。

【胡须】
17. 脸两侧各画三根细长的黑色胡须线，向上和向下扇形伸出。（长毛犬可省略）

【帽子 — 参考图的关键配件】
18. 头顶戴一顶[帽色]条纹毛线帽 #______，帽顶带[球色]毛球 #______。
19. 帽子戴在两只耳朵之间，两只耳朵必须完整露在帽子两侧，不要被遮住。

【笔触与描边】
20. 粗黑描边约 3px 等宽，线条略有抖动和毛边，保留手绘感。
21. 颜色冲出描边线之外，做越界上色，不要精准填色。
22. 蜡笔油画棒质感清楚，笔触和纸感可见，颜色饱满；颗粒要克制，不要大量刺眼白色划痕或伪高光，不要平滑渐变。

【背景】
23. 背景用明亮、高饱和的纯色大块平涂，参考最初样板的鲜亮青蓝底色气质；[按宠物毛色与帽子配色随机选择协调色相，每张图可变化，避免连续重复，不选粉灰、雾面或低饱和浅色] #______。背景干净、近乎平涂，只保留轻微自然蜡笔质感，不画场景、渐变或明显纹理。

【严格禁止】
不要写实毛发、不要渐变、不要光影、不要阴影、不要高光、不要 3D 渲染、不要动漫风格、不要精修质感、不要身体、不要爪子、不要腿、不要尾巴、不要除毛线帽外的道具、[背景杂物清单]、不要嘴巴、不要舌头、不要[错误耳型]、不要省略[招牌特征]。

整体气质：丑萌、呆滞、天真、可爱、大胆留白。
```

## 模板结构（双宠）

在单宠模板基础上，替换【招牌特征】段为两块独立差分块：

```
【关键要求：这是两只 DIFFERENT 的狗，绝对不能画成同一只狗的复制版】

【LEFT DOG — 左边这只：[品种]】
- 体型 [SMALL 小型犬／LARGER 大一号]
- 头型 [ROUND CIRCLE 小圆头，脸颊鼓／OVAL 长椭圆，下巴方]
- 耳朵 [形态 + 英文大写关键词]… 绝对不要画成[另一只的耳朵形态]
- 毛发 [画法关键词 CURLY FLUFFY／SMOOTH FLAT／LONG STRAIGHT SHAGGY]
- 毛色 [按部位分色]
- 眼距 [略宽／略窄]，鼻子 [细小／更大更黑]
- 戴[小号／大号][帽色]帽 #______，帽顶[球色]毛球 #______

【RIGHT DOG — 右边这只：[品种]】
- 体型 …（同上七项，逐项与左边形成对比）

【两宠构图】
two heads side by side，左边小、右边大，肩并肩居中。ONLY 有两颗头和一点点脖子，不要身体、不要爪子、不要腿、不要尾巴、[原照道具]、[背景杂物]。
```

## 背景色参考表（鲜明高饱和，按宠物和帽子随机搭配、轮换使用）

背景参考最初样板的亮青蓝与大色块效果；每次随机换协调色相，但维持鲜亮、饱满、干净，不用灰调或粉雾浅色。

| 色系 | 推荐色码 | 搭配提示 |
|---|---|---|
| 鲜亮青蓝（原始样板气质） | #079DBE | 适合橘、棕、白、灰色宠物 |
| 湖蓝 | #168FC2 | 适合暖白、金棕或深色宠物 |
| 草绿 | #58A832 | 适合白色、灰色或黑色宠物 |
| 明黄 | #E8BD24 | 适合黑灰、白色或冷色宠物 |
| 橘红 | #E9683D | 适合白色、灰色或黑色宠物 |
| 紫罗兰 | #8458B5 | 适合奶油色、金色或浅灰宠物 |
| 玫红 | #D94C83 | 适合白色、灰色或深色宠物 |

## 提示词参数

- 单宠可�� `input_fidelity: medium`
- 双宠必须用 `input_fidelity: high`，模型才能分清两只
- `quality: high` 用于正式交付
